Ribose Vulnerability Feeds

This site publishes machine-readable Open Source Vulnerability (OSV) and GitHub Security Advisory (GHSA) JSON feeds for tracked Ribose software packages.

Index endpoints

  • /feeds/osv/index.json — OSV index keyed by package and PURL.
  • /feeds/ghsa/index.json — GHSA index for tracked packages.

Tier A per-package OSV feeds

  • /feeds/osv/rnp.json — rnpgp/rnp (pkg:github/rnpgp/rnp)
  • /feeds/osv/metanorma.json — metanorma/metanorma (pkg:gem/metanorma)
  • /feeds/osv/cla.json — riboseinc/cla (pkg:github/riboseinc/cla)
  • /feeds/osv/identity.json — ribosei/identity (pkg:github/ribosei/identity)

Tier A per-package GHSA feeds

  • /feeds/ghsa/rnp.json — rnpgp/rnp
  • /feeds/ghsa/metanorma.json — metanorma/metanorma
  • /feeds/ghsa/cla.json — riboseinc/cla
  • /feeds/ghsa/identity.json — ribosei/identity
